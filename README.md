# 景区智能设备运营资料与试点监管

景区正在试点伴游机器人、助行外骨骼和自助影像设备。本项目在设备资料底座
（`registry.py` + `data/devices.json`）之上，建设了面向文旅智能设备试点的
监管服务，覆盖型号准入、试运行审批、变更管理、事故处置与公众查询，避免
准入证书与真实部署脱节。

## 监管服务（`src/scenic_devices/supervision.py` + `service.py`）

- **型号档案**：厂商按型号维护能力边界、固件与硬件版本、传感器、隐私处理、
  安全测试证据（带有效期）和维护方案；登记时接入现有设备类型与安全限制
  （影像能力必须说明隐私处理，需交接人员的设备要求景区配置人员）。
- **试运行申请**：景区结合地形、客流与人员配置申请限定范围的试运行；
  技术、无障碍、安全、数据保护四类审查可并行提交，但结论齐全、全部通过
  且证据在批准日仍有效才可发证。
- **批准记录**：证书写明适用场景、人数上限与复评日期，并锁定固件与硬件
  版本；部署时固件不一致即被拒绝。
- **变更管理**：固件升级、关键零件更换或扩大使用范围必须提交新申请，
  批准后旧证书作废，不能套用旧证书。
- **事故处置**：事故、投诉与抽检异常按严重度触发单点暂停、同型号排查或
  全面撤销；整改后的恢复只能来自有记录的复核，全面撤销须重新申请准入。
- **追溯与公开**：监管人员可从一次部署追到对应证据与审查责任人
  （`trace_deployment`）；景区只能选用当前有效型号（`available_models`）；
  公众查询（`public_catalog`）只显示适用范围与风险提示，不暴露传感器、
  维护方案等商业秘密。
